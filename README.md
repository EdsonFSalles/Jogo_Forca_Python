# 🎯Objetivo
Contruir um algoritimo que consuma os dados de um documento .txt e use para validar condições. Para esse modelo foi usado o Jogo Da Forca.
- contruir logica de algotimo
- criar para setar Score
- lê documento com dados para validação

Mini projeto criado em aula para inserir logica de algoritimos na pratica com uma linguagem de alto nivel

# ⚙️Logica do sistema
- cria documento para setar score dos jogadores
- cria cadastro jogador com atributo nome
- lê valores do dumento com valores para validações
- cria com valores de texto usando Print a representaçao do enforcado
